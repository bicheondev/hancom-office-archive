# Hancom Office 2014 research gaps

These product/update tracks are known or strongly indicated, but an exact
public installer filename or surviving official CDN object has not yet been
verified. They are intentionally not invented as normal download candidates.

- Hancom Office Hwp 2014 for Mac RTM installer (pre-VP)
- Hancom Office 2014 English full installer
- Hancom Office 2014 English trial and its surviving update packages
- EasyPhoto 3 RTM / non-VP installer or trial
- Complete historical Windows patch sequence, not merely surviving cumulative packages
- Full historical Mac 2014 updater feed/package archive
- Institution/contract-specific education, government, ILA, ALA and Open License media

## Confirmed but unresolved direct object

- `hncUpdate90P1.exe` — Hancom Auto Update 2014 bootstrap patch. The current
  Hancom download center still lists “자동업데이트 2014”, and the historical
  filename is documented, but the modern page does not expose a stable direct
  CDN URL in static HTML. The acquisition script probes Hancom-owned path
  candidates and records the result.
